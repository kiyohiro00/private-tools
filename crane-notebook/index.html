アクセストークンの作り方
  1. GitHubの右上アイコン → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
  2. Repository access で Only select repositories を選び、このリポジトリだけを指定
  3. Permissions の Repository permissions で Contents を Read and write にする
  4. 作成されたトークンを上の欄に貼り付けて「接続する」

トークンはこの端末のブラウザの中だけに保存され、GitHubにもチャットにも送りません。他人の端末では接続しないでください。記録（data.json）はPublicのリポジトリに保存されるので、誰でも見られます。

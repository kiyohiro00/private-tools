# private-tools

ブラウザで使える自作ツールの保管庫です。遊び用のツールを置いています。
1つのHTMLファイルで動くものが中心です。

公開URL: https://kiyohiro00.github.io/private-tools/

> 名前に `private` と付いていますが、リポジトリは**Public**です。
> 一般に公開してよいものだけを置きます。個人情報・APIキー・会社の情報は入れないでください。

## フォルダ構成

```
index.html          ツール一覧のトップページ
_template/          新しいツールのひな形（コピーして使う）
ツール名/index.html  各ツール（フォルダ名は英小文字とハイフン）
```

## ツールを追加するには

1. `_template/` をコピーして `ツール名/` を作り、`index.html` を書き換える
2. トップの `index.html` にある `TOOLS` に1件追加する
3. コミットして push すると、数分でGitHub Pagesに反映される

## ルール

- 1ツール = 1フォルダ、入口は `index.html`
- データやキーをHTMLに埋め込まない（入力は使う人のブラウザの中だけで扱う）
- 外部のライブラリを使うときは、バージョンを固定して読み込む
